서용식 개인 홈페이지 사용 안내

1. 홈페이지 열기
- 압축 파일을 받았다면 먼저 압축을 풉니다.
- index.html을 두 번 클릭하면 Microsoft Edge 또는 Google Chrome에서 열립니다.
- HTML, CSS, 그림 도식, 입력 기능이 index.html 한 파일에 들어 있습니다. 인터넷 연결이나 별도 프로그램 설치는 필요하지 않습니다.

2. 경력 입력 및 저장
- 경력 영역의 흰색 입력 칸에 주요 근무 경력, 주요 수행 업무, 전문 활동을 입력합니다.
- ‘경력 저장’을 누르면 아래 ‘저장한 경력 소개’에 반영됩니다.
- 저장된 내용은 같은 컴퓨터의 같은 브라우저에만 저장됩니다. 브라우저 데이터 삭제, 다른 브라우저 사용, 사이트 주소 변경 시 저장 내용을 다시 볼 수 없을 수 있습니다.
- 입력한 내용은 원본 HTML 파일에 기록되지 않습니다. 다른 컴퓨터로 옮기거나 파일로 공유하려면 별도로 파일에 반영해야 합니다.

3. 소개 문구 및 연락처 수정
- index.html을 메모장으로 열고 Ctrl+F로 [이메일 주소 · 확인 후 입력], [전화번호 · 확인 후 입력], [활동 지역 · 확인 후 입력]을 찾아 실제 정보로 바꿉니다.
- 주요 업무 문구는 요구사항을 바탕으로 만든 초안입니다. 실제 업무 범위와 다른 표현은 실제 내용에 맞춰 고칩니다.
- 저장할 때 UTF-8 인코딩을 유지합니다. 파일 이름이 index.html.txt가 되지 않도록 확인한 뒤 Ctrl+S로 저장하고 브라우저에서 F5를 누릅니다.

4. 공개 범위
- 이 HTML 파일은 열어도 인터넷에 자동 공개되지 않습니다.
- 온라인 사이트는 별도로 게시해야 합니다. GitHub Pages를 공개 저장소에서 배포하면 누구나 사이트에 접근할 수 있습니다.
- 문의 전송 기능은 포함되어 있지 않습니다.
